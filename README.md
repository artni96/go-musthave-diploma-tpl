# go-musthave-diploma-tpl

# Подготовка проекта к запуску
В корневой директории проекта создайте файл .env и заполните его в соответствии с файлом .env-example.

# Взаимодействие с проектом
## Список доступных команд
```
make help
```

## Запуск проекта
Запуск всех сервисов через docker compose (accrual-system, gophermart-db, gophermart-app)
```
make run
```
## Сервис accrual-system
### Запуск сервиса
- на MacOS
```
make as-darwin-arm64
```
или
```
./cmd/accrual/accrual_darwin-arm64
```
- на Linux
```
make as-linux
```
или
```
./cmd/accrual/accrual_linux_amd64
```

При запуске бинарного файла напрямую доступен флаг ```-a``` - адрес сервиса (по дефолту -  ```localhost:8080```)

## Сервис gophermart-app
### Подготовка сервиса к запуску
Поддерживаемые конфигурации:

- адрес и порт запуска сервиса: переменная окружения ОС ```RUN_ADDRESS``` или флаг ```-a```;
- адрес подключения к базе данных: переменная окружения ОС ```DATABASE_URI``` или флаг ```-d```;
- адрес системы расчёта начислений: переменная окружения ОС ```ACCRUAL_SYSTEM_ADDRESS``` или флаг ```-r```.

Приоритет конфигурационных методов сервиса:

```
Переменные окружения .env < Флаги < Переменные окружения ОС
```

### Запуск сервиса

- Соберите бинарный файл
```
go build -o ./cmd/gophermart/gophermart-app ./cmd/gophermart
```
- Запустите его с необходимыми переменным окружения и/или флагами

```
go run ./cmd/gophermart
```

- Альтернативный запуск в режиме разработчика - stdout DEBUG логов
```
make dev
```

## Запуск тестов
- Создайте тестовую базу данных
```
make up-test-db
```

- Запустите тесты
```
make test
```

## Дополнительный команды
- Завершение работы проекта (всех сервисов)
```
make down
```

- Завершение работы тестовой базы данных
```
make down-test-db
```
